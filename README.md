# Netflix India Market Disruption Strategy 2026

## Overview
An independent strategy case study analyzing why Netflix India underperforms despite the world's lowest pricing — and a 10-pillar framework to fix it.

Built with real market data from JustWatch, EY-IAMAI, HSBC, and Media Partners Asia.

---

## The Problem
- Netflix India holds only **16% SVOD market share** with **~20M subscribers**
- Population penetration: just **0.01%** in a country of 1.4 billion
- Three core barriers: **content accessibility**, **theatre dependency**, and **piracy (₹8,700 Cr lost/year)**
